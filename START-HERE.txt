PRIVATE APPS SCRIPT
-------------------
Code.gs belongs in the live Google Apps Script project connected to the JOTA-JOTI Sheet.
Do NOT upload Code.gs to the public GitHub repository.

1. Open the live sheet.
2. Extensions → Apps Script.
3. Replace the existing backend with Code.gs from the Apps Script package.
4. Save.
5. Run setupEOISystem() once and approve permissions.
6. Deploy / update the Web App as Execute as Me with access configured for the public site.
7. Open /admin and sign in with the generated admin password.
8. Run System & Settings → Import / repair live sheet content.

WHAT THE ADMIN NOW DOES
-----------------------
Participants: edit live Users rows, resend account email, print, CSV download, password PDF.
Activities: create/edit/archive, category, photo, URL/HTML instructions, embedding and leader controls.
Categories: create/edit/archive and reuse/upload logos.
Links: create/edit/archive, URL/HTML content, embedding, approvals, moderation and logos.
Photos & Logos: directly uses the existing Logos sheet and can upload new media.
Emails: paperwork reminders and bulk email tools.
System: repair, setup, cache clearing, settings and audit log.

LIVE SHEET / LOGO IMPORT
------------------------
The admin page reads the existing live sheet data. A row with LogoKey=chat automatically finds Logos.LogoKey=chat and uses its LogoURL. The same rule works for categories, links and activities. Direct LogoURL/PhotoURL values are also honoured.

RUN THIS ONCE AFTER DEPLOYMENT
------------------------------
Use /admin → System & Settings → Import / repair live sheet content.
Then refresh. Existing rows are kept; missing headers/defaults are added; logo/photo URLs are resolved from the existing Logos sheet; raw HTML content is detected; blank Active values default to active.

PASSWORD OUTPUTS
----------------
The Participants page has:
  - Print password sheet
  - Download account CSV
  - Download password PDF
These contain private credentials and must be kept with restricted event paperwork.

NEVER PUT THE USERS SHEET, PASSWORD EXPORTS OR PRIVATE CODE.GS IN A PUBLIC GITHUB REPOSITORY.
