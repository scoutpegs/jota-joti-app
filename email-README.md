# Boulder Scout Group email templates

`parent-welcome-template.html` is the parent/participant onboarding email. `leader-welcome-template.html` is the Leader onboarding email.

The live Apps Script generates the same layout using the real account values from the `Users` sheet. The templates use placeholders such as `{{username}}`, `{{pin}}`, `{{password}}`, `{{websiteURL}}` and `{{sfh3URL}}` for preview/copy purposes.

Parent workflow: account details, website, setup guide, required youth forms, terms and setup instructions.

Leader workflow: SFH 3 only, no Y3 process, Scout Learn account assistance and JOTA-JOTI account details.

Boulder site: https://scoutpegs.github.io/jota-joti-app/
SFH 3: https://learn.scout.org/resource/sfh-3-being-safe-online
