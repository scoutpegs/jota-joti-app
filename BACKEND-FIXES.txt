1. Make the bound spreadsheet lookup reliable in a web-app request.

ADD this helper once near the top of Code.gs:

function getSpreadsheet_() {
  const props = PropertiesService.getScriptProperties();
  const savedId = String(props.getProperty('JOTA_JOTI_SPREADSHEET_ID') || '').trim();
  if (savedId) {
    try { return SpreadsheetApp.openById(savedId); }
    catch (e) { props.deleteProperty('JOTA_JOTI_SPREADSHEET_ID'); }
  }
  const active = SpreadsheetApp.getActiveSpreadsheet();
  if (!active) {
    throw new Error('JOTA-JOTI cannot find its Google Sheet. Open the spreadsheet, run setupEOISystem once from Extensions > Apps Script, approve permissions, then redeploy the web app.');
  }
  props.setProperty('JOTA_JOTI_SPREADSHEET_ID', active.getId());
  return active;
}

2. Replace every occurrence of:

SpreadsheetApp.getActiveSpreadsheet()

with:

getSpreadsheet_()

This affects diagnostics, sheet reads, admin functions, form setup, backups and other spreadsheet operations.
